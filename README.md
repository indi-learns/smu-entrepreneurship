# SMU Cox Entrepreneurship — Class 5 Lab site

## Publish on GitHub Pages
1. Create a public repository and upload everything in this folder (keep the `assets` folder).
2. Add your AI-generated video as `assets/hero.mp4`.
3. Repository Settings → Pages → Source: "Deploy from a branch" → `main`, `/ (root)` → Save.
4. Your URL is `https://<username>.github.io/<repository>/`. Submit that in Canvas.

## Files
- `index.html` — landing page (video, button to page two, pathfinder, feature description)
- `programs.html` — second page
- `styles.css`, `site.js` — design and behavior
- `chatbot.js` — chatbot on both pages; set `LAB3_BOT_URL` at the top to swap in your Lab 3 bot
